CHARTE GRAPHIQUE - PLATEFORME D'INVESTISSEMENT LOCATIF
(alignée sur le code le 20/11/2026 : les valeurs ci-dessous sont celles des variables de styles.css)

============================================================
1. CONCEPT VISUEL
============================================================
L'identité visuelle repose sur trois piliers :
- Expertise : Rigueur des données et des calculs.
- Prestige : Aspect patrimonial et immobilier.
- Technologie : Interface moderne, fluide et réactive.

============================================================
2. TYPOGRAPHIE
============================================================
Charte unique (décidée le 20/11/2026, audit A4) : deux familles, toutes deux servies par le site
(dossier vendor/fonts, format woff2, aucune requête vers Google Fonts) :
- Texte et titres (H1, H2, H3, boutons, formulaires) : Inter, police variable (graisses 400 à 800).
  Les titres se distinguent par la graisse (600-700), pas par une autre famille.
- Chiffres & Data (montants, ratios, dates, KPI) : IBM Plex Mono (graisses 400, 500, 600) - "outil de précision".
Les PDF (décision, dossier bancaire) utilisent les mêmes fichiers. Plus aucune autre police :
Manrope, Cormorant Garamond, Montserrat, JetBrains Mono et Space Grotesk ont été retirées.

Mise en oeuvre : variables --font-heading / --font-body / --font-display / --font-base (Inter) et --font-mono
(IBM Plex Mono) dans styles.css ; ne jamais écrire un nom de police en dur dans une règle. Les boutons et champs
héritent la police du texte (button, input, select, textarea { font-family: inherit }).
Chargement : font-display: swap et préchargement (<link rel="preload" as="font" crossorigin>) d'Inter latin et des
trois graisses de Plex Mono dans index.html et owned.html, pour qu'aucun changement de police ne soit visible au
premier affichage (test : tests/playwright/audit-lot3.mjs, scénario A4, sous 200 ms de latence). Un fichier de
police remplacé doit changer de nom (cache d'un an, immutable, voir firebase.json).

============================================================
3. COULEUR D'ACCENT UNIQUE : L'INDIGO (décidé le 20/11/2026, audit A5)
============================================================
Une seule couleur d'action dans toute l'interface (boutons principaux, onglet actif, curseurs, liens accentués,
bouton flottant, badges) : l'indigo. L'or de l'ancienne charte (#C5A059 / #D4AF37) n'existe plus que dans le
logo. Les PDF et le rapport d'un bien suivent la même règle.
Trois variables, toutes définies dans les deux thèmes (ne jamais écrire une teinte d'accent en dur ; pour une teinte
transparente : rgba(var(--primary-rgb), 0.12)) :
- --accent        : fonds, bordures, focus, barres actives.
- --accent-text   : TEXTE accentué (liens, onglet actif, libellés) - plus foncé en clair, plus clair en sombre, pour
                    atteindre 4,5:1 sur les fonds de cartes.
- --on-accent     : texte posé SUR un fond --accent (blanc en clair ; presque noir en sombre, car le blanc
                    n'atteignait que 3,5:1 sur l'indigo clair du thème sombre).
Contrôle : tests/playwright/audit-lot3.mjs, scénario A5 (14 écrans x 2 thèmes) échoue si un texte accentué ou posé
sur un fond accent passe sous 4,5:1 (3:1 pour un grand texte), ou si l'ancien or réapparaît.
Exception documentée : les graphiques à plusieurs séries gardent une palette catégorielle (indigo/bleu/vert d'eau/
ocre, _projectionPalette dans owned-portfolio.js) pour que les séries restent distinguables ; une série unique
(cash-flow cumulé du dashboard) prend l'accent. Les couleurs d'état (ci-dessous) ne sont jamais l'accent.

============================================================
Cible : Confiance, clarté, lecture prolongée de rapports.

COULEURS :

- Fond de carte (Cards) : #F8F5EF
- Texte principal : #1F1B17
- Texte secondaire : #5A534A
- Bordures & Séparateurs : #D6CDBF
- Accent : #4F46E5 (texte accentué #4338CA, texte sur accent #FFFFFF)
- Succès : #136B34 / Alerte (risque) : #B42318 / À surveiller : #8F4706 / Neutre : #64748B

EFFETS :
- Ombres : 0 2px 8px rgba(60, 45, 25, 0.08) (cartes), 0 8px 24px rgba(60, 45, 25, 0.11) (surélévation)
- Bordures : 1px solid #D6CDBF
- Arrondis (Radius) : 6px, 8px (Composants), 12px (Cards), 16px (modales), pastille 9999px

============================================================
6. ÉLÉMENTS D'INTERFACE (UI)
============================================================
- Boutons Primaires : fond --accent, texte --on-accent.
- Boutons Secondaires : fond transparent, bordure fine, texte du thème ; le survol passe à l'accent.
- États de survol (Hover) : réduction de l'opacité de 12% ou légère élévation (shadow).
- Graphiques : série unique = accent (trait plein, remplissage translucide) ; plusieurs séries = palette catégorielle.
- Tons d'état (classes --excellent, --positive, --neutral, --watch, --negative) : jamais l'accent.
- Icônes (décidé le 20/11/2026, audit A7) : une seule famille, SVG en ligne, style "Line", trait constant de 1,5 px,
  bouts et angles arrondis, couleur = celle du texte (currentColor), grille de 16 px. Source unique : icones.js (30
  icônes). Plus aucun emoji couleur ni glyphe (✦ ✕ ✓ ⚠ ☀ ☾ ↑ ↓ ← → ▶ ● ○) comme icône d'interface ; les flèches ← → ne
  subsistent que dans une phrase. Toute icône est décorative (aria-hidden) : un bouton qui n'a QUE une icône porte un
  aria-label (ou un texte masqué). Dans un gabarit JS : ${icone('croix')} ; dans le HTML statique : <i
  data-icone="croix"></i> (remplacé au démarrage) ; pour un texte venant de l'utilisateur : definirTexteAvecIcone().
  Contrôle : tests/test_icones.mjs et tests/playwright/audit-lot3.mjs, scénario A7 (24 écrans).
  Exceptions : le code mort de ui.js, les PDF (leur propre mise en page) et les <option> de tri (▲ ▼, une option ne
  contient que du texte).

============================================================
7. RÈGLES D'USAGE
============================================================
- Espacement : Toujours utiliser un multiple de 4px (8, 16, 24, 32) pour les marges.
- Hiérarchie : Toujours mettre le Rendement Brut/Net en police Mono et en gras.
- Contraste : WCAG AA (4,5:1 pour le texte courant, 3:1 pour un grand texte) dans les DEUX thèmes ; vérifié par le
  scénario A5 ci-dessus.
